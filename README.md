# 📦 CXE Package Manager (cxepm)

Менеджер пакетов для старых версий Windows (Vista SP2+). Работает без установки, не требует winget и умеет ставить программы одной командой.

## 🚀 Быстрый старт

1. Скачай `cxepm.exe` из [Releases](https://github.com/CatinDev2014/CXE-Win/releases) (портативная версия) или установи через `CXE_PkgMan_Setup.exe`.
2. Положи в удобную папку (например, `C:\cxepm\`).
3. Запусти. Введи команду:
   ```cmd
   cxepm install opera
   ```

## 🛠 Команды

```cmd
cxepm update index          # Обновить индекс
cxepm list                  # Список пакетов
cxepm search <слово>        # Поиск
cxepm info <пакет>          # Инфо о пакете
cxepm install <пакет>       # Установить (последнюю версию)
cxepm install <пакет> <вер> # Установить конкретную версию
cxepm install <п1> <п2> ... # Установить несколько пакетов
cxepm install <файл.cxe>    # Установить локальный .cxe (офлайн)
cxepm install <файл.cxepkg> # Установить пакетный архив
cxepm upgrade               # Обновить все
cxepm remove <пакет>        # Удалить из базы (файлы останутся)
cxepm purge <пакет>         # Полное удаление (деинсталлятор из реестра)
cxepm exec <пакет>          # Запустить приложение
cxepm history               # История установок
cxepm clean                 # Очистка кэша
cxepm repo [set <url>]      # Настройка репозитория
cxepm doctor                # Диагностика
```

## 📂 Форматы

**`.cxe`** — ZIP-архив. Внутри `manifest.cm` и (опционально) `.exe`. Если в манифесте есть `url` — скачает установщик. Если нет — запустит локальные `.exe` из архива.

**`.cxepkg`** — ZIP-архив с несколькими `.cxe` внутри. Устанавливает по очереди.

**`.cm`** — текстовый манифест:
```text
name'Opera'
ver'95'
arch'x86_32'
deskription'Браузер для Windows 7'
type'program-internet-browser'
url'https://get.geo.opera.com/pub/opera/desktop/95.0.4635.90/win/Opera_95.0.4635.90_Setup.exe'
```
*(Поле `deskription` — историческое, не меняется. `url` может содержать несколько ссылок через запятую.)*

## 🏗️ Добавление пакета

1. Создай `manifest.cm` через `cmgen.exe`.
2. Упакуй в ZIP, переименуй в `имя_пакета.cxe`.
3. Закинь в репозиторий `CXE-Win`.
4. Добавь в `index.json`:
   ```json
   { "твой_пакет": { "1.0": "твой_пакет/твой_пакет_1.0.cxe" } }
   ```
5. Выполни `cxepm update index`.

## 🐛 Проблемы

* **Ошибка JSON** — проверь запятые и скобки в `index.json`.
* **Антивирус ругается** — добавь `.exe` в исключения.
* **Не работает на XP** — минимальная версия Windows Vista SP2.
* **`purge` не находит деинсталлятор** — программа не прописала себя в реестре. Удали вручную.
